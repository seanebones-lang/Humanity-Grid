# Contributor provenance and attribution

Humanity Grid is intended to make scientific and technical work inspectable.
The repository should apply the same standard to its own changes.

## What a contribution must make clear

- The contributor has the right to submit it under the repository license.
- The commit accurately identifies its author; do not use another person's name
  or an organization as an author without authorization.
- Third-party code, data, models, papers, images, and generated artifacts have
  their source and applicable terms identified in the pull request and in the
  resulting files where practical.
- A contribution does not claim independent execution, scientific validation,
  custody, authorship, or review that did not occur.

## Developer Certificate of Origin

Every commit submitted in a pull request must carry a Developer Certificate of
Origin sign-off. Create it with:

```bash
git commit -s -m "docs: describe the source of a packaged artifact"
```

By signing off, the contributor certifies under the
[Developer Certificate of Origin, version 1.1](https://developercertificate.org/)
that they have the right to submit the work under the applicable project terms.
The sign-off is an authorship and licensing representation; it is not a transfer
of copyright and it does not establish scientific validity.

## Recognition

`AUTHORS.md` records project origin and acknowledged contributors. Git history,
review records, and experiment manifests remain the more precise record for a
particular change or artifact. Recognition does not determine copyright
ownership, contributor status, authorship of a paper, or scientific credit.
