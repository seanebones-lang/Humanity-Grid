# External review and Proof B

Humanity Grid invites skeptical, bounded review of EXP-001 Proof A. Review is
not endorsement, and a failed replay, criticism, or conclusion that the package
is not scientifically adequate is a useful contribution.

## What to review

1. Start with [Proof A: scientific review and local replay](PROOF_A_REVIEW.md).
2. Verify the frozen artifact package:

   ```bash
   python3 proofs/EXP-001-v1/tools/verify.py
   ```

3. Review the package [artifact-rights boundary](../proofs/EXP-001-v1/LICENSES.md).
4. Use Witness’s public [review request](https://github.com/seanebones-lang/witness/blob/main/REVIEW_REQUEST.md), [review protocol](https://github.com/seanebones-lang/witness/blob/main/REVIEW_PROTOCOL.md), and [review template](https://github.com/seanebones-lang/witness/blob/main/REVIEW_TEMPLATE.md).
5. Consult the [independent-review log](https://github.com/seanebones-lang/witness/blob/main/REVIEW_LOG.md) for published feedback and responses.

## Scope

The package demonstrates that stated local artifacts and a Grid-to-Witness
record contract can be inspected and replayed. It does not demonstrate a drug
candidate, docking accuracy, biological activity, efficacy, independent
execution, external validation, or a deployed volunteer-computing network.
